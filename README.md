# RailFOD23 Presentation

This repository contains the presentation for **RailFOD23: Intelligent Railway Foreign Object Detection & Safety Monitoring System**.

## How to use

1. Double-click the `index.html` file to open it in any modern web browser (Chrome, Edge, Firefox, etc.).
2. Use `ArrowRight` or `Space` to go to the next slide.
3. Use `ArrowLeft` to go to the previous slide.
4. Press `F` to toggle Fullscreen mode for the presentation.

## Folder Structure

The presentation is built entirely within a single HTML file to keep it simple and portable. All styles (CSS) and logic (JS) are embedded inside `index.html`.

Assets like background images and icons are located in the `assets/` directory.
